# Spotter — `labs/reference/`

This directory is a **complete** café host. CI `--replay` runs it.

**Open it only if you are stuck.** The S13 audit is a recall test of
`cafe_host/loop.py`. If you read this tree first, S13 becomes a recognition
test and the number it produces is no longer evidence of ownership.

Allowed: `labs/schemas.py`, `labs/house_rules.py`, `labs/menu.py`, the protocol
markdown. Those are the wire contract and the fixtures, not the lift.
