# S13 bridge — unaided rebuild audit

**Not a lab directory session.** Protocol: `lesson.html`.

Easy path: audit a system **you already own**. Hard path: audit the `cafe/`
package you built in S01–S12 — core `cafe/loop.py`, suite `cafe/evals` — as
**recall**, not as “open the files and summarize.” The optional café-host lab in
`labs/cafe_host/` is a separate, secondary target if the learner took that path.

## Companion constraints (strict)

- You may restate what the protocol *asks* (closed-book rebuild audit,
  evidence, no new features).
- You must **not** write the audit, walk the learner through `engine.py` as
  a substitute for recall, or paste a reconstructed loop from memory as
  their submission.
- If they are stuck on the *rules of the sitting* (time box, what counts as
  peeking), clarify process only.

The learner's own `cafe/` package is the target, and the companion cut also
ships a complete café host. Both make S13 easier to cheat and more important
to keep unaided. If they read `cafe/` or `cafe_host/` during the audit, the
number is recognition, not ownership — say that once, then stop helping with
content.

No `--replay` target for S13 in `run.py`.
