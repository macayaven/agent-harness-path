# The Agent Harness Path v0.2.0

These notes describe the v0.2.0 course contents. The
[GitHub release record](https://github.com/macayaven/agent-harness-path/releases/tag/v0.2.0)
provides publication status, date, exact commit and public acceptance evidence.
A release marked Pre-release is still a verification candidate; use the optional
guided bundle only after its application release is promoted.

This release keeps the existing 14-session course in
`macayaven/agent-harness-path` and adds two optional ways to go deeper. The first
is a replay-first trivia-host lab spine across S01–S12. The second is a calibrated
six-week post-core study overlay. Neither changes the zero-network, zero-key native
notebook route or makes S13/S14 required.

It also adds the complete schema-v2 curriculum used by the optional CourseWeave
student pilot: all 12 notebooks, 36 required reading/notebook/self-check
activities, and the notebook-free S13/S14 protocols. Original notebook cells and
output-free state remain protected; learner answers and study records belong
outside the Git checkout.

## Highlights

- Script-free static SVG diagrams for every lesson, with meaningful text
  alternatives and pinned source/asset freshness checks.
- A cumulative optional lab path with committed cassettes, contract tests and a
  reference baseline; live provider mode stays explicit and outside CI.
- Full-course study guidance, observation templates and separate immediate and
  delayed transfer exercises with unaided/review boundaries.
- Native navigation and course-kernel fixes across all 12 notebooks.
- Stronger S11 budget qualifications, corrected cross-artifact claims and repaired
  source links.
- Local-clone lesson delivery with optional videos streamed from the existing
  public bucket; no GitHub Pages mirror is published.

See the complete [changelog](../../CHANGELOG.md) for Added, Changed and Fixed
details and the [course map](../../COURSE-MAP.md) for session coverage.

## Install and compatibility

After the course tag is public, the native route is:

```bash
git clone --branch v0.2.0 --single-branch https://github.com/macayaven/agent-harness-path.git
cd agent-harness-path
uv sync --frozen
uv run jupyter lab
```

Open `lessons/index.html` for the course reader. Preserve edited notebooks and
other learner work outside the checkout before switching versions.

CourseWeave is versioned and released separately. Public v0.1.0 is incompatible
with this schema-v2 course. Its v0.2.0 release owns
`agent-harness-path-courseweave-0.2.0-macos.tar.gz` and `SHA256SUMS`. Wait until the
application release lists both files and is no longer marked Pre-release, then
verify the named bundle as `OK` before extraction and follow the
guided setup in the root README. The native route remains complete without it.

Course licenses remain Apache-2.0 for code and CC BY 4.0 for educational content.
The separate CourseWeave application uses PolyForm Shield 1.0.0, a source-available
license restricting competing product use. This does not change the course's
reuse permissions or the ownership of learner-created work. See the
[course license](../../LICENSE) and
[platform licensing guide](https://github.com/macayaven/courseweave/blob/main/docs/LICENSING.md).

Use the
[course feedback form](https://github.com/macayaven/agent-harness-path/issues/new?template=course-feedback.yml)

raw chats, participant content, private project details, local paths and full
notebook/work products. No telemetry or learner file is submitted automatically.

## Evidence and limits

The [student-pilot report](../verification/student-pilot-2026-09-13.md) and
[JSON receipt](../verification/student-pilot-2026-09-13.json) identify the exact
locally tested artifacts and observed checks. They separate synthetic contracts,
installed application behavior and work that still requires a learner or human
participant. They do not certify general accessibility, learning efficacy,
teacher workflows, arbitrary live providers, compliance or production readiness.

Release promotion follows [the runbook](../RELEASING.md). Before publishing the
GitHub Release, the exact release commit must pass the repository's Python
3.11/3.12 workflow, all 12 notebook executions, generated HTML and link checks,
lab contracts/replays, public-evidence review, clean-tree check and asset checksum
verification.
