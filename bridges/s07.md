## The gap

The toy retries a bad model turn with a cap. The host, after each user line
and `run_loop`, calls `turn_policy_hit` on the new suffix. If hit and
`retries < 3`: delete messages from `after_user:`, append a short repair
user line (`Policy {hit}: do not leak… Use tools only.`), run the loop
again. Never raise approved difficulty on retry. If still hit:
`stop_reason=retries_exhausted`.

Every run should end with
`stop_reason ∈ {completed, retries_exhausted, turn_cap, budget_exceeded, rejected, invalid_edit, invalid_decision, policy_refusal}`.
Print it (the returned dict and `state["stop_reason"]`). No ambiguous exits.
